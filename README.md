# GSAA — Ghana Sociological & Anthropological Association

Official website for the Ghana Sociological and Anthropological Association.

## Local preview

```bash
python -m http.server 8080
```

Open [http://localhost:8080](http://localhost:8080).

## Deploy (GitHub Pages)

This repo deploys automatically on push to `main` via GitHub Actions.

1. Push to GitHub
2. In the repo: **Settings → Pages → Build and deployment → Source: GitHub Actions**
3. For custom domain `gsaa.org.gh`, add the DNS records GitHub shows under **Settings → Pages → Custom domain**
